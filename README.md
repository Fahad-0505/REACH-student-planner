# REACH Student Planner

A mobile-first student planning web application developed for REACH ADHD Coaching & Consultancy.

## Live app
https://reach-student-planner-final-v4.onrender.com

## Purpose
The planner helps students reduce overwhelm by turning assessment requirements into manageable steps, planning study around real-life commitments, using short focus blocks, and recognising progress positively.

## Included flows
- Home, Today, Assignments, Planner and Progress
- Semester setup and unit management
- Unit outline upload/review workflow
- Add Assignment: Details → Brief → Student Understanding → Understanding Check → Plan
- Task completion and growth points
- Availability and commitments
- .ics calendar import
- Focus & Recharge timer
- Rewards/progress view
- Profile/settings
- Local data backup export/import
- Installable/offline-friendly PWA support

## Data model
The current handover release is local-first. Working planner data is stored in the user's browser on that device. Use Export backup before clearing browser data or moving to another device.

No real student data is bundled with the repository. Demo content is fictional.

## Academic integrity
The planner assists students to understand, organise and plan academic work. It does not write assignments.

## Source
Production is intentionally dependency-light: HTML, CSS and JavaScript with no paid runtime dependency.
